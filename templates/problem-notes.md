# 题解笔记模板

> 每题 3–5 行，超过 10 行说明你在抄题解，不是在总结。
> 存在一个文件夹里（建议按知识点命名），考前翻一遍比重刷有效。

```markdown
## <题目名>（<来源+题号>）

- 知识点：`<topics.json 的 id>`
- 难度：<CF rating / 洛谷难度>
- 关键一步：<一句话。例：把"至少 k 个"转成"总数 − 至多 k−1 个">
- 我卡在：<具体哪一步。例：没想到可以离线排序>
- 下次触发：<看到什么信号该想到它。例：区间计数 + 可离线 → 树状数组>
- 复杂度：O(____)
- 是否重写：☐ 24h 后重写 ☐ 一周后重做
```

## 示例

```markdown
## P1908 逆序对（洛谷）

- 知识点：`bit-fenwick` / `merge-sort`
- 难度：普及+/提高-
- 关键一步：离散化后按值插入树状数组，查询"已插入且比它大的个数"
- 我卡在：没想到要先离散化，直接按值开数组爆空间
- 下次触发：值域大 + 计数 + 可离线 → 离散化 + 树状数组
- 复杂度：O(n log n)
- 是否重写：☑ 24h 后重写
```

## 反例（不要这样写）

```markdown
## P1908

这题用树状数组做。先离散化，然后...
（后面抄了 30 行题解）
```

**问题**：没有"我卡在哪"，没有"下次怎么想"，一周后完全想不起来。抄题解是最常见的伪学习。
