# 中国赛场：CSP → NOIP → 省选 → NOI → 集训队

> 读这个文件当且仅当：用户的目标是中国 OI 路线，或需要判断"我现在这个水平在国内处于什么位置"。
> 这里是**结构与判据**。名额、分数线、时间每年变，具体以 CCF/NOI 官网当年通知为准（链接见文末）。

## 一、一句话地图

```
CSP-J/S 第一轮（9 月，笔试）
        ↓ 达本省分数线
CSP-J/S 第二轮（10 月底，机试 4 题）
        ↓                         ↘  J 组到此为止（初中阶段目标）
NOIP（11 月底，4 题 4.5h，高中在校生）
        ↓ 省一/省二/省三
省选（次年 3–4 月，NOIP + 省选加权）
        ↓ 进省队（A/B 类名额）
NOI（7 月，两试两天，每天 3 题 5h）
        ↓ 金牌 ≈ 进国家集训队（50 余人）
CTT（12 月，3 场）→ 前 30 → CTS（2 月，2 场）+ 作业互测 → 前 6 面试+论文 → 国家队 4 人
        ↓
IOI（次年 7–8 月）
```

WC 冬令营（1–2 月）与 APIO（5 月）是这条主线上的两次"练兵 + 评奖"，不直接决定晋级，但对省队选拔有加分。

## 二、CSP-J/S（CCF 非专业级软件能力认证）

- 分 **J（入门级）** 与 **S（提高级）** 两组，各考两轮。
- **第一轮**：笔试（涂卡），2025 年 J 组 9:30–11:30、S 组 14:30–16:30。
- **第二轮**：机试 **4 题**，2025 年 J 组 8:30–12:00、S 组 14:30–18:30（J 3.5 小时，S 4 小时）。
- **报名资格**：当年 9 月 1 日前满 12 周岁；不限年级（小学生也可报 J 组）。
- **晋级**：第一轮达到**本省**分数线才能进第二轮；各省自行划线，比例不固定。
- **第一轮卷面（2026 J 组）**：43 题 / 100 分 / 120 分钟 —— 单选 15×2=30；阅读程序 3 大题共 40；完善程序 2 大题 ×5 空 ×3=30。S 组题型同构、难度更高。

**注意**：第一轮不是"随便过"，每年都有大量选手卡在笔试。专项准备见 [preliminary.md](preliminary.md)。

## 三、NOIP（全国青少年信息学奥林匹克联赛）

- **资格**：高中在校生（部分省份允许初中生以"体验"身份参加但不评奖，以本省通知为准）。
- **形式**：2025 年为 11 月 29 日 8:30–13:00，**4 题 4.5 小时**，免费。
- **评奖**：全国获奖率约 67%（一等约 20%、二等约 22%、三等约 25%）。2025 年基准线 137 / 108 / 86（满分 400）——**分数线随题目难度浮动，不要拿往年线当目标，看排名**。
- **作用**：省一是省选的门票，也是综合评价/校测的材料；省二、省三主要用于经历性材料，实际权重看各校口径。

## 四、省选与省队

- **成绩构成**：NOIP 成绩 + 省选成绩加权（部分省加入冬令营成绩），各省比例不同。
- **省队名额**：分 A 类（每省基础名额，通常 5 人）与 B 类（按上一年成绩奖励）。NOI 2026 为 A 类 160 + B 类 143 = 303 人。
- **同校限制**：同一学校入选省队的人数不超过本省 A+B 名额的 1/3；女生第一名不占该比例。这条对"强校扎堆"影响极大，选校时要问清楚。
- **女生通道**：NOI 女生竞赛（每年 11 月）优胜者可入围 NOI，是独立于省队的路径。

## 五、NOI（全国青少年信息学奥林匹克竞赛）

- **赛制**：两试两天，每天 3 题 5 小时，OI 赛制（赛后评测、按测试点给分）。
- **规模与奖项**：NOI 2025（绍兴）522 人，金 50 / 银 152 / 铜 85；NOI 2026（青岛）金 54 / 银 154。金牌比例约 10%，银牌约 30%。
- **金牌 = 进国家集训队**（约 50 人），获得高校保送资格。这是整条路径上唯一"一步到位"的节点。

## 六、国家队选拔（CTSC 的现行形态）

- NOI 前约 50 名进入国家集训队。
- **CTT**（12 月，3 场）占 54% → 取前 30。
- **CTS**（2 月，2 场）占 36% + 作业与互测 10%（自出题 + 120 题题单）。
- 前 6 名进入面试与论文答辩 → 选出 4 人国家队。
- 所以"进集训队"不等于"进国家队"；后者还要再打三个月，且论文/出题能力计入成绩。

## 七、评测环境与 0 分重灾区

- **NOI Linux 2.0**：Ubuntu 20.04.1 + kernel 5.4 + **GCC/G++ 9.3.0** + GDB 9.1 + Code::Blocks 20.03。2021-09-01 起为 NOI 系列与 CSP-J/S 的标准环境。
- **编译**：`g++ -O2`，`-std` 以题面为准（9.3 默认 gnu++14，很多题面会写 `-std=c++14`）。**STL 允许**。
- **文件 IO**：中国 OI 赛制绝大多数题目要求 `freopen("xxx.in","r",stdin)` / `freopen("xxx.out","w",stdout)`，题面会指定文件名。**写错文件名 = 0 分**，不是"少一点分"。
- **交卷目录**：按准考证号建文件夹，每题一个子文件夹，源码文件名必须是题目指定的英文名（如 `graph.cpp`）。交错位置 = 0 分。
- **本地模拟**：练习时就用 `freopen` 写，别养成 `cin` 直读的习惯，否则赛场必翻车。

## 八、《NOI 大纲》怎么用

- 发布方：CCF NOI 科学委员会。2021 首版，2023 一修，**现行 2025 年修订版**（2025-04-18 发布）。
- **不是 A/B/C 三级**，而是按 **入门级 / 提高级 / NOI 级** 三档组织，每条知识点标 **难度系数 1–10**（入门 1–5、提高 5–8、NOI 级 7–10；系数 10 仅用于 CTS）。
- 结构：入门级 5 章（计算机基础与编程环境 / C++ / 数据结构 / 算法 / 数学）、提高级 5 章、NOI 级 4 章，合计约 230 条。
- **2025 修订的主要变化**（说明大纲在动，别背旧版）：新增前缀和/差分、`bitset`、扫描线、多维 DP、错排/圆排列、线性基；Manacher 由 NOI 级下放提高级；删除格雷码、次小生成树、跳跃表、二维线段树。
- **用法**：拿它当"检查清单"，不是"学习顺序"。顺序看 `data/topics.json` 的 `prereq`；大纲告诉你"这条要不要学、学到什么深度"。

## 九、升学：把概率说清楚

- **保送**：NOI 金牌 → 国家集训队 → 具备保送资格（2025 年起集训队可直接进入清华姚班等）。
- **强基计划**：正在收紧。破格入围原本要求五科竞赛决赛银牌及以上；2025 年 8 所高校取消、部分高校提高到金牌；**2026 年再增 4 所，39 所中已有 15 所不设竞赛破格**，同时"单科小破格"增加到 16 所。全国五科集训队约 260 人/年、金银牌约 1900 人/年——**银牌不再等于强基门票**。
- **综合评价 / 校测**：省一有分量，但各校、各省差异大，必须以当年招生简章为准。
- **现实预期**：从零到省一通常需要 1.5–3 年系统训练；到 NOI 金牌需要天赋 + 训练量 + 教练/环境，且仍有随机性。给家长的时间线要按"乐观/正常/保守"三档给。

## 十二、常见误解

| 说法 | 事实 |
| --- | --- |
| "NOI 大纲分 A/B/C 三级" | 错。分入门级/提高级/NOI 级三档，每条标难度系数 1–10 |
| "CSP 第一轮随便过" | 错。笔试刷掉的人比想象中多，阅读程序与完善程序是主要失分点 |
| "省一就能保送" | 错。保送看 NOI 金牌/集训队；省一是省选门票与综评材料 |
| "NOIP 分数线每年差不多" | 错。随题目难度浮动，看排名不看绝对分 |
| "进集训队就是国家队" | 错。还要过 CTT/CTS + 论文答辩，50 进 4 |
| "强基银牌就能破格" | 过时。2026 年 39 所中 15 所已取消竞赛破格 |
| "用 cin 就行， freopen 无所谓" | 中国 OI 赛制下文件 IO 写错直接 0 分 |
