# 选题：从"随便刷"到"每道题都有用"

> 读这个文件当且仅当：用户问"我该刷什么题"、"题单怎么选"、"为什么刷了很多没进步"。
> 核心结论：**刷题的收益不取决于数量，取决于"难度是否落在学习区"和"做完是否复盘"。**

## 一、难度带：3:5:2

| 区间 | 占比 | 特征 | 作用 |
| --- | --- | --- | --- |
| 舒适区 | 20% | 20 分钟内能独立 AC | 保持手感、巩固模板 |
| **学习区** | **60%** | 想 20–60 分钟，需要提示或看部分题解 | **唯一产生进步的区间** |
| 恐慌区 | 20% | 完全没思路，看题解也吃力 | 开阔视野，但要限时，不能耗一整天 |

判断学习区的实操标准：**看题解前能想出第一步**。想不出第一步 = 恐慌区；看完题解觉得"就这么简单"但自己想不到 = 典型学习区。

## 二、每道题的标准流程

```
读题（3 分钟）
  → 写数据范围与目标复杂度（必做）
  → 想 15–20 分钟，写下思路（哪怕是错的）
  → 卡住：看提示，不看代码
  → 仍卡住：看题解，但只看"关键观察"那一段，关掉，自己写
  → 写完：造 3 组边界数据自测
  → AC 后：写 3–5 行笔记（关键一步 + 为什么自己没想到）
  → 24 小时后：凭记忆重写核心代码
```

**没有第 7、8 步，这道题等于没做。**

## 三、选题的五个判据

1. **有明确的知识点归属**：能说清它练的是 `data/topics.json` 里的哪个 id。说不清 = 不成体系。
2. **难度在你当前 rating ±200**：低于 -400 是浪费时间，高于 +400 是看天书。
3. **有质量保证**：官方题 / 高赞题 / 有题解 / 有数据。来源不明的题可能题意有歧义。
4. **能独立验证**：有小样例、能写暴力对拍。没有数据意识的题不要碰。
5. **做完能说出一句话结论**：如果做完什么都说不出，换题。

## 四、检索式（照抄可用）

### Codeforces

- 按知识点：`problemset` → 右侧 tag 多选（AND）→ rating 区间填 `[1200, 1500]` → 按 rating 升序。
- 补弱项：只勾 1 个 tag（如 `dp`），rating 从低到高扫 20 题，做出 15 题为止。
- 综合训练：不选 tag，rating 设 `[当前-100, 当前+200]`，随机做。
- 限时模拟：`contests` → 选一场 Div.3/Div.2 → `Virtual participation`。

### AtCoder

- 基本功：ABC 的 C/D 题按顺序刷（ABC 每场固定 7 题，难度递增稳定）。
- 系统课：典型 90 問（90 题，★1–7 递进）；AtCoder Library Practice（练模板）。
- 手速：Chokudai SpeedRun 001（60 分钟 12 题）。

### 洛谷

- 按难度：入门 / 普及- / 普及 / 普及+·提高- / 提高 / 提高+·省选- / 省选·NOI- / NOI·NOI+·CTS（8 档）。
- 按主题：题单功能搜"树形DP"、"最短路"等关键词。
- 按来源：NOI 官网历年真题（最权威）；LibreOJ 的省选/NOI 归档。

### USACO

- 按级别：Bronze → Silver → Gold → Platinum，每级在 usaco.guide 有模块化顺序。
- 按模块：每个模块末尾有"Practice"题单，直接照做。

## 五、题单怎么搭

一份合格的周题单（5–6 题）：

| 位置 | 数量 | 作用 |
| --- | --- | --- |
| 模板题 | 1 | 本周知识点的裸模板，确认"会写" |
| 变形题 | 2 | 同知识点的不同问法，确认"会用" |
| 综合题 | 1 | 与旧知识点结合，确认"能迁移" |
| 挑战题 | 1 | 略高于当前水平，允许做不出 |
| 复习题 | 1 | 上周或上上周的知识点，防遗忘 |

**不要**一份题单全是同一难度、同一题型——那是"练习"，不是"训练"。

## 六、什么时候该看题解

| 情况 | 建议 |
| --- | --- |
| 想 20 分钟没有任何进展 | 看**提示**（不是题解） |
| 有思路但进行不下去 | 看题解的"关键观察"，然后关掉自己写 |
| 想了 60 分钟仍在原地 | 直接看题解，但看完必须**合上重写** |
| 看完题解觉得"懂了" | 24 小时后重写；写不出 = 没懂 |
| 同一题看了题解还看不懂 | 超纲了，标记"暂缓"，换题 |

**看题解的三种错误用法**：边看边抄（等于没做）、看完不重写（一周后忘光）、只看代码不看推导（学不到思维）。

## 七、复盘笔记模板（每题 3–5 行）

```markdown
题：<题目名 / 链接>
知识点：<topics.json 的 id>
关键一步：<一句话，例如"把'至少 k 个'转成'总数 - 至多 k-1 个'">
我卡在：<具体哪一步，例如"没想到可以离线排序">
下次遇到：<触发信号，例如"看到'区间内计数'且可离线 → 想树状数组">
复杂度：O(n log n)
```

一周 5 题 × 20 周 = 100 条笔记。这 100 条才是你真正的"知识库"，比任何教材都贴身。

## 八、常见误区

| 误区 | 为什么错 | 改法 |
| --- | --- | --- |
| "刷够 500 题就变强" | 舒适区的 500 题不如学习区的 100 题 | 按 3:5:2 配比 |
| "按题单从头刷到尾" | 题单假设了你的起点 | 先诊断，再跳着刷 |
| "只做难题" | 基础不牢，难题也做不出 | 舒适区 20% 不能省 |
| "看题解等于学会" | 看懂 ≠ 能写 ≠ 能想 | 24 小时后重写 |
| "一道题做完就过" | 没有笔记 = 没有沉淀 | 每题 3–5 行 |
| "不限时" | 赛场能力是独立技能 | 每周至少 1 次限时 |
| "只刷一个专题" | 比赛不按专题出题 | 每周 2 天混合题单 |
| "用提交次数代替思考" | 每次提交都该有一个假设 | 提交前写下"我认为这次改了 X" |

## 九、题量参考（按目标）

| 目标 | 累计题量（学习区） | 说明 |
| --- | --- | --- |
| CSP-J 一等 | 150–250 | 以模板题 + 变形题为主 |
| CSP-S 一等 / NOIP 省一 | 300–500 | 覆盖提高级全部知识点 |
| 省队 | 600–1000 | 含 100+ 道省选/NOI 真题 |
| NOI 金牌 | 1500+ | 且要有高质量模拟赛与论文阅读 |

题量只是下限。**同样 500 题，有笔记和没笔记的人，差距在一倍以上。**
