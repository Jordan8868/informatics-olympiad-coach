# 水平定位：L0–L7

> 读这个文件当且仅当：用户问"我什么水平"、"我该学什么"、"我还差多远"、"这份计划适合我吗"。
> 定位不靠感觉，靠**可观测信号**：他独立做出过什么、独立写不出什么、比赛中拿过多少分。

## 用法

1. 先让对方看"信号"列，自评最像哪一级（**看"能做到"，不看"学过"**）。
2. 用"不能做"列交叉验证：如果下一级的"不能做"他其实能做到，就往上调一级。
3. 定位之后，只给**下一级**的训练重点。跨两级给内容 = 劝退。

## 八个级别

### L0 · 零基础

| | |
| --- | --- |
| 能做到 | 会用电脑；没写过代码，或只抄过"Hello World" |
| 不能做 | 变量、循环、数组、函数都说不清 |
| 信号 | 没装过编译器；不知道 `int` 和 `double` 的区别 |
| 目标赛事 | 无（先学语言） |
| 到 L1 的路 | 4–8 周：变量/分支/循环/数组/函数/结构体，每天 1 小时，做 60–100 道入门题 |

### L1 · 语法关（CSP-J 初赛水平）

| | |
| --- | --- |
| 能做到 | 独立写出 50 行以内的模拟、枚举、排序调用；会读入输出、会调试语法错误 |
| 不能做 | 递归写不利索；不知道复杂度是什么；DP 没概念 |
| 信号 | CF 800–1000 能做出 A 题；洛谷"入门"能独立做 |
| 目标赛事 | CSP-J 第一轮 |
| 到 L2 的路 | 8–12 周：递归、二分、前缀和、简单贪心、线性 DP、STL；每周 4–6 题 |

### L2 · 普及（CSP-J 复赛 / USACO Bronze）

| | |
| --- | --- |
| 能做到 | 独立写出 DFS/BFS、二分答案、0/1 背包、并查集；会用 `sort` + 自定义比较 |
| 不能做 | 区间 DP、树形 DP、线段树；复杂题不会拆解 |
| 信号 | CF 1200–1400 稳定做出 A/B；洛谷"普及/普及+"能独立做；CSP-J 复赛 200+ |
| 目标赛事 | CSP-J 复赛一等、CSP-S 第一轮 |
| 到 L3 的路 | 10–16 周：图论基础、树、树状数组、区间/树形 DP、单调栈；开始限时训练 |

### L3 · 提高-（CSP-S / USACO Silver）

| | |
| --- | --- |
| 能做到 | 独立写 Dijkstra、拓扑排序、树状数组、简单线段树；会写对拍 |
| 不能做 | 复杂 DP 优化、网络流、树链剖分；赛场上时间分配混乱 |
| 信号 | CF 1400–1600；CSP-S 复赛 100–200；USACO Silver 满分 |
| 目标赛事 | CSP-S 二等/一等、NOIP 省三 |
| 到 L4 的路 | 12–20 周：线段树进阶、最短路建模、树形 DP、状压/数位 DP、组合数学 |

### L4 · 提高（NOIP 省一 / USACO Gold）

| | |
| --- | --- |
| 能做到 | 独立写 lazy 线段树、树剖、Dinic、2-SAT；能在一场 4 小时内拿到 250+ |
| 不能做 | CDQ/整体二分、SAM/SA、LCT；难题的"第二步转化"经常卡住 |
| 信号 | CF 1600–1900；NOIP 省一；USACO Gold 通过 |
| 目标赛事 | NOIP 省一、省选入围 |
| 到 L5 的路 | 16–24 周：网络流建模、点分治、莫队、字符串算法、DP 优化 |

### L5 · 省选-（省队边缘 / USACO Platinum）

| | |
| --- | --- |
| 能做到 | 独立写树套树、点分治、AC 自动机、斜率优化；能读懂集训队论文的一部分 |
| 不能做 | 复杂构造、交互题、论文级技巧；代码稳定性不足 |
| 信号 | CF 1900–2200；省选进省队或差一点；USACO Platinum 有分 |
| 目标赛事 | 省队、NOI 铜牌 |
| 到 L6 的路 | 20–30 周：专题突破 + 大量限时赛 + 论文精读 |

### L6 · 省选 / NOI（省队主力）

| | |
| --- | --- |
| 能做到 | 独立完成 NOI 前两题；会 CDQ、SAM、LCT、多项式；能设计部分分策略 |
| 不能做 | IOI 级构造与交互；稳定性与心态 |
| 信号 | CF 2200–2500；NOI 铜/银；省选稳定进队 |
| 目标赛事 | NOI 银牌、集训队边缘 |
| 到 L7 的路 | 以赛代练 + 论文 + 出题/互测 |

### L7 · 集训队 / IOI

| | |
| --- | --- |
| 能做到 | NOI 金牌；CF 2500+；能独立出题、写题解、做论文答辩 |
| 不能做 | 已经是国内前 50，剩下的靠天赋、状态与细节 |
| 信号 | NOI 金牌 / 集训队；IOI 奖牌 |
| 目标赛事 | 集训队、国家队 |

## 三维短板诊断

定位之后，判断短板在哪一维——三者的训练方法完全不同。

| 维度 | 表现 | 怎么练 |
| --- | --- | --- |
| **知识** | 看到题不知道属于哪一类；某个专题的题全不会 | 按 `data/topics.json` 的 prereq 补节点，每节点 3–5 题 |
| **实现** | 思路对但写挂、调一小时、常数大 | 限时手写模板；每天一道"必须在 30 分钟内 AC"的题；强制对拍 |
| **策略** | 会做但没时间做、先做难题卡死、部分分不拿 | 模拟赛 + 强制时间分配表 + 赛后复盘（[contest.md](contest.md)） |

**最常见的误判**：把"实现差"当成"知识缺"，于是不停学新算法，成绩不动。判断方法：给他一道**刚讲过思路**的题，限时 40 分钟。写不出来 = 实现问题；写出来但变形就不会 = 知识问题。

## 定位提问脚本

复制这段话问用户：

```
为了给你排一份能执行的计划，我需要三个信息：
1. 最近一次比赛的成绩（赛事名 + 分数/奖项），或者 Codeforces/AtCoder 的 rating；
2. 你最近独立做出来的最难一道题（题目名或链接），以及花了多久；
3. 每周能稳定投入多少小时（不含上课时间）。
另外：你的目标赛事和截止时间是什么？
```

三个信息缺一个，就按"保守一级"给方案，并说明"信息不足，先按 Lx 排，两周后用 checkpoint 校正"。

## 各级的典型卡点（对症下药）

| 级别 | 最常卡在 | 一句话处方 |
| --- | --- | --- |
| L1 | 递归想不清、数组越界 | 画调用树；每道题手算 n=3 |
| L2 | 不会把暴力优化、DP 状态设计 | 先写暴力再想"重复算了什么" |
| L3 | 图论建模、赛场上写不完 | 每天 1 道限时 40 分钟的题 |
| L4 | 难题第二步、代码稳定性 | 专题突破 + 强制对拍 |
| L5 | 综合题、时间不够 | 模拟赛 + 部分分策略 |
| L6 | 稳定性、心态、构造 | 以赛代练 + 论文 + 出题 |

## 时间预期（给家长用）

以每周 8–10 小时、有教练/环境支持为前提：

| 起点 → 目标 | 乐观 | 正常 | 保守 |
| --- | --- | --- | --- |
| 零基础 → CSP-J 一等 | 8 个月 | 12 个月 | 18 个月 |
| 零基础 → NOIP 省一 | 2 年 | 2.5–3 年 | 4 年 |
| 省一 → 省队 | 1 年 | 1.5–2 年 | 3 年 |
| 省队 → NOI 金 | 1 年 | 2 年 | 3 年 |

**必须说清楚的三件事**：省一以上每往上一级，淘汰率都在 5–10 倍；训练时间不是唯一变量（教练、同伴、题目质量影响很大）；这条路不影响高考以外的选择，但要提前想好"停在哪里"。
