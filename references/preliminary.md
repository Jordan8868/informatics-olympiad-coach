# CSP 第一轮（初赛）专项

> 读这个文件当且仅当：用户要准备 CSP-J/S 第一轮，或问"初赛怎么复习"、"阅读程序怎么做"。
> 初赛不是"随便过"。它考的是**计算机基础 + 代码阅读能力**，和复赛的算法能力是两套技能。

## 一、卷面结构（2026 J 组）

| 题型 | 题量 | 分值 | 建议用时 |
| --- | --- | --- | --- |
| 单项选择 | 15 题 × 2 分 | 30 | 30–40 分钟 |
| 阅读程序 | 3 大题（判断题 + 单选题） | 40 | 35–40 分钟 |
| 完善程序 | 2 大题 × 5 空 × 3 分 | 30 | 35–40 分钟 |
| 合计 | 43 题 | 100 | 120 分钟 |

S 组题型同构、难度更高。**通过线由各省划**，通常远高于 60 分，别按"及格"准备。

## 二、单选高频考点（30 分）

### 必背速查

| 考点 | 要点 |
| --- | --- |
| 进制转换 | 二↔十↔十六；小数部分乘 2 取整；十六进制 4 位一组 |
| 补码 | 负数 = 取反 + 1；8 位补码范围 −128~127；`-x = ~x + 1` |
| 位运算 | `x & (x-1)` 消掉最低位的 1；`x & -x` 取 lowbit；`x >> 1` 等于除以 2（向下取整） |
| 完全二叉树 | n 个节点的完全二叉树高度 = ⌊log₂n⌋+1；叶子数 = ⌈n/2⌉ |
| 二叉树性质 | 度为 0 的节点数 = 度为 2 的节点数 + 1（n₀ = n₂ + 1） |
| 握手定理 | 所有顶点度数之和 = 2 × 边数；奇度顶点个数为偶数 |
| 哈夫曼 | WPL = Σ(权值 × 深度)；每次合并最小的两个 |
| 排序复杂度 | 快排平均 O(n log n)、最坏 O(n²)、不稳；归并 O(n log n)、稳；堆排 O(n log n)、不稳；冒泡/插入 O(n²)、稳 |
| 二分比较次数 | ⌈log₂(n+1)⌉；n=1000 约 10 次 |
| 卡特兰数 | C(2n,n)/(n+1)：n 个节点的二叉树形态数、合法括号序列数 |
| 容斥 | \|A∪B\| = \|A\|+\|B\|−\|A∩B\| |
| 图的存储 | 邻接矩阵 O(n²) 空间；邻接表 O(n+m) |
| 递归/递推 | 手工展开 3–4 层找规律 |
| 字符串 | `strlen` O(n)；字符数组末尾 `'\0'`；ASCII 大小写差 32 |
| 指针 | `*p` 取值、`&x` 取地址、数组名即首地址 |
| 计算机常识 | 存储单位（1KB=1024B）、CPU/内存/缓存层次、操作系统基本概念、网络协议分层 |

### 单选策略

- 15 题里通常 10 题是"会就会"，3 题要算，2 题是常识/偏门。
- **先做会做的，标记不确定的**，最后回头。
- 计算题写过程，别心算——初赛的计算错一步就全错。

## 三、阅读程序（40 分）

给一段 20–40 行的代码，回答"输入 x 时输出是什么"、"这行改成 y 会怎样"。

### 四步法

1. **扫结构**：几个函数？主函数干了什么？有没有递归？
2. **找输入输出**：读什么、输出什么、循环边界。
3. **代小数据**：把题目给的输入代进去，**逐行在纸上追踪变量**（不要心算）。
4. **验证**：用另一组自己造的数据再跑一遍，确认理解正确。

### 高频陷阱

| 陷阱 | 例子 |
| --- | --- |
| 参数改了行为就变 | `gcd(a, a%b)` 改成 `gcd(a, b)` |
| 去重/排序是否必要 | 代码里排序只是为了输出好看，不影响答案 |
| 前导零/输出格式 | `printf("%05d")`、末尾空格 |
| 搜索顺序 | DFS 序不是升序；BFS 按层 |
| 死循环边界 | `while(i < n)` vs `while(i <= n)` |
| 整数除法截断 | `7/2 == 3`，负数向零取整 |
| 递归终点 | 少一层/多一层 |
| 数组下标从 0 还是 1 | 影响边界与循环次数 |

### 判断题技巧

- "该程序的时间复杂度是 O(n log n)" —— 数循环层数 + 看有没有 `sort`/`log` 级跳转。
- "若输入 …，输出 …" —— 老实代数据，别猜。
- "把第 x 行改成 y，程序仍能正确运行" —— 想清楚改的这行在什么条件下被执行。

## 四、完善程序（30 分）

给一段挖了 5 个空的代码 + 题目描述，从选项里选。

### 方法

1. **先读题面**：这段程序要解决什么问题？输入输出是什么？
2. **再看空的位置**：空在循环条件、边界判断、递归参数、初始化、还是更新语句？
3. **代入选项验证**：把 4 个选项分别代入，用一组小数据跑一遍，看哪个不越界、不越界、结果对。
4. **优先排除**：明显越界的（`i <= n` 当数组开到 n）、明显死循环的、明显类型不匹配的。

### 高频陷阱

| 陷阱 | 正确写法 |
| --- | --- |
| 越界 | `i + 1 < len` 而不是 `i + 1 <= len` |
| 整数除法 | 上取整写 `(a + b - 1) / b` |
| 进位条件 | `>=` 还是 `>`（十进制进位是 `>=10`） |
| 递归终点 | `if (l == r) return` 还是 `l >= r` |
| 区间端点 | 左闭右开还是双闭 |
| 初始化 | `ans = 0` 还是 `ans = -INF`（求最大值时） |
| 边界特判 | `n == 1` 时是否要单独处理 |

## 五、四周备考计划

| 周 | 内容 | 产出 |
| --- | --- | --- |
| 1 | 计算机基础 + 进制 + 位运算 + 树/图性质 | 背完上面的速查表；做 5 套单选 |
| 2 | 排序/查找/复杂度 + 组合计数 | 每天 1 套阅读程序（限时 15 分钟） |
| 3 | 阅读程序专项（每天 2 大题）+ 错题归因 | 整理"我常错的 5 类" |
| 4 | 完善程序专项 + 全真模拟（3 套，限时 120 分钟） | 每套 ≥ 80 分 |

**真题来源**：NOI 官网历年资料、洛谷 CSP 题库、各省市模拟卷。至少做 5 套完整真题。

## 六、考场策略

- 120 分钟，按 40/40/40 分配，最后留 10 分钟检查填涂。
- **不会的先标记，不要空着**（单选没有倒扣）。
- 阅读程序一定要**在纸上追踪**，不要心算。
- 完善程序宁可多代一组数据，也不要凭感觉选。
- 最后检查：姓名/准考证号/答题卡填涂是否错位。

## 七、常见误区

| 误区 | 事实 |
| --- | --- |
| "初赛背背就行" | 阅读程序 40 分靠的是代码阅读能力，背不出来 |
| "初赛通过线 60 分" | 各省划线，通常远高于 60 |
| "S 组和 J 组题型一样，难度也一样" | 题型同构，S 组明显更难（尤其阅读程序） |
| "只刷单选" | 单选只占 30 分，大头在阅读程序和完善程序 |
| "做过一遍就行" | 初赛题要**限时**做，否则考场节奏必乱 |
